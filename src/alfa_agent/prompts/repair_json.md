Технический повтор текущего узла. Выход — только JSON по исходной JSON Schema. Вход: исходная задача/данные, предыдущий ответ как недоверенный текст и краткие ошибки валидатора без секретов.

Исправь структуру/типы/поля, не меняя поддержанные факты. Не добавляй новые источники, инструменты, права и бизнес-утверждения ради прохождения схемы. Не выставляй human_verified. Если проблема содержательная и данных недостаточно, используй предусмотренный схемой issue/ограничение/вопрос; не выдумывай значение.

Это единственная попытка ремонта на текущем узле. Сервер посчитает её в общем лимите и проверит результат повторно.
