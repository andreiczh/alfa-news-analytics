# Переработка платформы 0.5.0 — правки команды от 25.10.2026

Статус: локальная приёмка завершена; публикация и проверка в Render предстоят. Исходник — [полный пакет пользователя](source-materials/product-revisions-2026-10-25.txt). Это продуктовые требования команды, не замена регламента организаторов. Ограничения моделей, собственного контроллера, бюджета и происхождения данных сохраняются.

## Матрица приёмки

| Требование | Реализация | Проверка |
|---|---|---|
| 1. Общие компания и роль | Серверные предпочтения, профиль сверху, CMO; локальных ролевых фильтров нет | CFO/CMO, перезагрузка, несколько компаний; роль не меняет права |
| 2. Полный профиль | Категории общих сведений, стратегии, финансов, рисков, приоритетов и свободных полей; имя, сайт, описание | Редактирование, версии, отдельный контекст компаний; нет постоянного бокового контекста |
| 3. AI-диалог | Реальная GLM, вопросы по известным данным/роли, проверка дословных опор, редактируемое предложение | Четыре поля сохранены только после подтверждения; защита старого предложения и отмена |
| 4. Обзор | Главное событие, связь с компанией, механизм, условия и действие; отдельные срочные сигналы | Сохранённая записка повторно используется без оплаты; без неё прогноз не выдумывается |
| 5. Новости | Объяснение значимости/влияния; контекст и конкуренты меняют ранжирование | Регрессии подтверждают изменение результата; охват штатной сети проверить в облаке |
| 6. Исследование | Связная записка, причины, опоры, влияние, риски/возможности, действия, базовый и альтернативный сценарии | Живая CFO-записка PARTIAL, два сценария, четыре поля контекста; числа/единицы/цитаты и отдельный семантический контроль |
| 7. Материалы банка | Подбор по компании/роли/приоритетам с объяснением; остальные доступны отдельно | CFO/CMO различаются; связь с исторической сталью/золотом не выдумывается |
| 8. UX/UI | Четыре раздела, профиль сверху, единый путь, постепенное раскрытие глубины | Видимый Chromium, четыре раздела на 390/320 px, экспорт и навигация без JS errors |
| 9. Семантика | Сообщение источника / интерпретация / гипотеза / условный сценарий | Применимость, дата/горизонт и следующий шаг; тестовые данные помечены |
| 10. Совместимость | Дополнительные таблицы; прежние результаты, файлы, избранное, история/обратная связь доступны | Все 155 автотестов прошли; новые провайдеры/зависимости не добавлены |
| 11. Сквозной путь | Профиль → диалог → подтверждение → новости/библиотека → исследование → сценарии/экспорт | Локально пройден; финальная облачная приёмка ещё требуется |

Успешный сохранённый результат повторно прошёл усиленные проверки. Это итерации разработки, не доказательство безошибочности модели. Мобильный QA-сценарий исправлен без повторения платного интервью.

## Critical review

### 1. Steelman

[Факт, высокая уверенность] Цель — единая система поддержки решения: пользователь задаёт компанию и роль один раз, подтверждает контекст и получает объяснимую аналитику с основаниями и условными сценариями.

### 2. Strengths

[Факт, высокая] Персонализация передаётся через сервер и неизменяемые снимки; роли не дают доступ к чужим компаниям. Контекст входит в отбор, опоры записки и рекомендации. Модель не сохраняет профиль автоматически. Необоснованные числа, единицы, опоры и несовместимые версии блокируются. Живые вызовы и ошибки сохранены в протоколе.

### 3. Weaknesses & risks

[Факт, высокая] Условный сценарий не доказывает будущий исход; численная вероятность не измерена. Материалы банка датированы, OCR и разметка не прошли полную экспертную приёмку. Локальный результат не подтверждает облачную сеть — нужен прогон после LIVE. Бесплатное хранение временное. Нет независимого relevance/recall benchmark, промышленной SSO и измерения бизнес-эффекта.

### 4. Hidden assumptions

[Допущение, существенное] Пользователь достоверно описывает компанию и вправе загрузить файлы. Подтверждение означает согласие, не истинность сведений. Публичные ленты/API доступны не всегда; сбой должен оставлять ограничение, а не выдуманную новость. Качественный горизонт планирования не означает перенос старого прогноза на текущий период.

### 5. What to verify

- [Факт, высокая] 155 тестов, Ruff, JS syntax, frozen install и локальная GUI-приёмка — проверены.
- [Не завершено] Финальный SHA: Render LIVE, свежие новости, AI-интервью и записка CFO, экспорт/мобильный экран/изоляция.
- [Остаётся для сдачи] Доступ жюри, Docker, экспертная разметка и отложенный benchmark. Эти задачи не маскируются релизом UX.

### 6. Confidence

90% в работоспособности проверенного прототипа и корректности обозначенных границ; окончательный облачный статус фиксируется отдельно. Это не оценка точности прогноза и не промышленная готовность.
