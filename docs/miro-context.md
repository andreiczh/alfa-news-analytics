Рабочее название «Пульс бизнеса» — решение для текущего интерфейса. В Miro есть кандидаты «Альфа Не босс / АНАЛЬФА», их утверждение командой не установлено.

Приоритет `! / !! / !!!` в интерфейсе отражает наличие оснований для проверки (контекст / продукт / явная договорная экспозиция), а не вероятность ущерба, оценку истинности новости или денежную существенность. Высокое относительное влияние без финансового знаменателя не утверждается.
