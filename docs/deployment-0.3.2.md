## Конфигурация

Build: `pip install --require-hashes -r requirements.lock && python -m alfa_agent build-case-index`. Start: `python -m alfa_agent serve`. Порт задаёт Render. Индекс CSV строится до запуска и открывается на чтение; гонка индексации исправлена в предыдущем релизе.

Секреты: `ALFA_LLM_API_KEY`, `ALFA_ACCESS_PASSWORD`, `ALFA_SESSION_SECRET`. Общий пароль не изменялся; отдельный секрет подписи добавлен на сервис без публикации значения. `.env*` и файл с паролем исключены из Git. Сессии старого формата потребуют нового входа с ФИ/компанией/должностью.

Состояние: `/tmp/alfa-state`, ephemeral demo. Новые файлы и история теряются после простоя/перезапуска; исходные примеры восстанавливаются. При стабильных секретах подписанная сессия может восстановить пустое личное пространство, но не потерянные файлы.
