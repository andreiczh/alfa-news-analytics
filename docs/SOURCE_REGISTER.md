## Данные компаний

Три CSV организаторов находятся в `data/case/`; индекс при сборке сверяется с хешами исходников и читается без изменения. Отдельно существуют явно синтетические профили и тестовые документы. Пользовательские файлы привязаны к личному рабочему пространству и не добавляются в общий репозиторий автоматически.

Повторная проверка индекса 24.10.2026 воспроизвела расхождение с пересказом вебинара: переводы `PAYER = BENEFICIARY` составляют **81,6587% суммы PAY_AMT**, **13,2929% суммы PAY_CNT** и **1,9851% строк**. Значение «3% количества» из DOCX не воспроизвелось. У **114 552** ID участников платежей отсутствует профиль компании. Полный локальный результат: `reports/v3/data-crosscheck.json`. Это разные знаменатели; доля строк не заменяет долю платежей.

`NEGATIVEMARK` не трактуется как негативный кредитный риск. Продуктовый флаг не превращается в остаток, ставку или договор. Платёжные суммы не объявляются выручкой. Выручку юрлиц группы нельзя механически складывать в консолидированную. CITY_NAME/RC_NAME и период платёжного набора сохраняют расхождения между первичным PDF и пересказом вебинара; они не сглаживаются выдуманной трактовкой.

## Внешние материалы при проверке

Официальные страницы Render использованы для конфигурации размещения, а документация OpenRouter — как справка по формату запросов, без утверждения о фактическом поставщике или тарифе организаторского API. Отдельно проверяется реальная совместимость API вызовами. Публичные страницы ЦБ и Альфа-Банка используются только при успешном чтении с сохранением URL и времени. Неуспешный доступ не считается прочитанным источником.

В облачном тесте версии 0.3.2 от 24.10.2026 прочитана `https://www.cbr.ru/`, дата публикации главной страницы неизвестна (`null`). Это не проверка сегодняшнего значения ставки. Страница `https://alfabank.ru/about/` не была успешно прочитана; её содержание не приписано компании. Bing RSS дал нерелевантные поисковые наводки; они не использованы как подтверждённые события. Новость об ИТ-тарифе в отдельном живом тесте явно синтетическая, а не наблюдавшееся рыночное событие.

Рабочее название «Пульс бизнеса» — решение текущего прототипа. Кандидаты названия из Miro, гипотезы об экономии времени, планы интервью и показатели opportunity/Kano из DOCX не объявлены утверждёнными или измеренными результатами.

В 0.4.0 используются прямые RSS ЦБ/РБК, резервный Интерфакс и Bing News по публичному имени компании. Издательская дата и дата извлечения разделены, дата агрегатора уступает явной дате издателя с сохранением происхождения. Текущая доступность каналов, первая пятёрка, сырые источники и подтверждение штатной сети Render отражены в отчёте 0.4.0; успешный отдельный запуск не означает полноты или SLA. Подборки не используют подготовленный список новостей из кейса.
