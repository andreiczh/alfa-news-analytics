## Запуск и данные

Build: `pip install --require-hashes -r requirements.lock && python -m alfa_agent build-case-index`. Start: `python -m alfa_agent serve`. `PYTHONPATH=src`, Python 3.12.14, порт задаёт Render. Исходные CSV/PDF не меняются. Схема SQLite дополняется таблицами предпочтений, контекста и очереди диалога; прежние отчёты сохраняют снимки.

Секреты прежние: `ALFA_LLM_API_KEY`, `ALFA_ACCESS_PASSWORD`, `ALFA_SESSION_SECRET`. Значения не публикуются. Signed HttpOnly-сессия и изоляция по владельцу; профессиональная роль не даёт дополнительных прав. Вход демонстрационный, банковская SSO не подключена.

Состояние `/tmp/alfa-state` временное: новые документы, история, контекст, подборки и отзывы могут потеряться после простоя/перезапуска. Стабильная подпись восстанавливает пустое личное пространство, не файлы. Экспортировать важные результаты. Это согласованный бесплатный режим хакатона.

RSS/ранжирование/персональная библиотека не расходуют модельные вызовы. Диалог и исследования работают через разрешённые модели API организаторов и общий дневной лимит. Тариф/рублёвый остаток неизвестен. Подтверждённые пользователем сведения остаются его сообщением, не внешней проверкой.

## Приёмка и откат

Локально: 155 тестов, Ruff, синтаксис двух JavaScript-файлов, frozen install, реальная GLM для интервью и записки, мобильные экраны 390/320 px. Облачный протокол добавляется после LIVE. Сценарии условные, `human_verified=false`; отсутствие внутренних банковских показателей приводит к PARTIAL.

Откат: проверенный код 0.4.0 `bb64a93b841496ddc12ed754e88fdcde8e7c8aa3`, deployment `dep-dbe6qu7avr4c739s4ieg`. Основания: неработающий вход/worker, раскрытие чужих данных, публикация вывода без оснований. Единичная недоступность внешней ленты при работающем резерве отражается как ограничение охвата.

Docker CLI локально отсутствует; Docker-сборка не объявляется проверенной. Нативная сборка Linux проверяется фактическим Render build.
