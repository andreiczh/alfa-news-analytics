## Запуск и данные

Build: `pip install --require-hashes -r requirements.lock && python -m alfa_agent build-case-index`. Start: `python -m alfa_agent serve`. `PYTHONPATH=src`, Python 3.12.14; порт задаёт Render. Индекс CSV готовится до старта и читается без изменения.

Секреты прежние: `ALFA_LLM_API_KEY`, `ALFA_ACCESS_PASSWORD`, `ALFA_SESSION_SECRET`. Значения не публикуются. Signed HttpOnly-сессия, отдельный серверный секрет, изоляция по сотруднику/компании. Это демо-вход, не банковская SSO.

Состояние `/tmp/alfa-state`, ephemeral demo. После простоя/перезапуска новые документы, история, подборки, отзывы и публичный кэш теряются. Стабильная подпись может восстановить пустое личное пространство, но не файлы. Датированные примеры кейса восстанавливаются; свежие новости собираются заново. Важные результаты экспортировать.

RSS/поиск/ранжирование не вызывают модель. Модельные запросы только через API организаторов, общий дневной лимит 500 руб., сброс 03:00 МСК; рублёвый остаток неизвестен. Прямые ленты/публичный поиск могут быть недоступны — охват показывается в интерфейсе. Никакой подготовленной RSS-ленты или подмены сети на Render нет.
